Q-Hold

Quality-hold coordination, repair tracking, inspections, production visibility, and approvals.

Start the Flask application

This project uses Flask and Jinja templates. Opening a file from qhold/templates with Live Server displays template code instead of running the application.

  1. In the project folder, double-click run_qhold.bat (or run it from a terminal).
  2. Wait until the terminal reports that the Q-Hold server is ready.
  3. Open the application at http://127.0.0.1:5000.

Demonstration only: sample records and the role selector are not production data or authentication.
